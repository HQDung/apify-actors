# Phase 12 plan: README and Store preparation

## Objective

Prepare conservative Store-facing metadata, README documentation, examples, benchmark evidence, limitations, and responsible-use guidance.

## Implementation

1. Confirm title and short description match the implemented product value.
2. Replace stale phase wording with complete user-facing documentation.
3. Document modes, mappings, outputs, controls, costs, limitations, FAQ, and roadmap.
4. Synchronize schema descriptions and sample inputs.
5. Run the Actor test, lint, format, schema, JSON, and diff checks.

## Acceptance criteria

- README claims only implemented and tested capabilities.
- Coverage and cost claims are conservative and qualified.
- Sample inputs match the final schema.
- Responsible-use and partial-evidence behavior are explicit.
- No pricing or publication action occurs automatically.
