# Changelog

## 0.1.0

- Added same-product cross-platform cluster matching with shared, platform-specific, dominant, and insufficient-evidence classifications.
- Added platform-partitioned issue clusters with deterministic IDs, review links, platform dimensions, and cluster index storage.
- Added shared per-review analysis, common mobile taxonomy, bounded analysis cost controls, optional native-fetch provider, fallback handling, and analysis records.
- Added runtime-neutral Google Play and Apple App Store source adapters, bounded raw collection, normalized review records, source diagnostics, and partial-failure handling.
- Added explicit Google Play and Apple App Store product mapping validation.
- Added cross-platform modes, input normalization, scoped mapping errors, and zero-collection run statistics.
- Added Actor schemas, samples, and phase-gated documentation.
