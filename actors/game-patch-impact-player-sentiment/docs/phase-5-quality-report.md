## Local runtime evidence

The packaged release was run with the bounded local matrix. The default elevated smoke produced one `ok` report for `646570`, 40 before/40 after samples, full/full coverage, 3 pages, 300 scanned reviews, 80 analyzed reviews, no warnings, and a 1.494-second per-game runtime. The local matrix also revalidated latest-patch fallback, custom-date, two-game, evidence-off, and invalid-style inputs; detailed case results are in `docs/phase-4-report.md`.

The first sandboxed matrix attempt logged `Memory snapshot failed: spawn EPERM` and a Steam `fetch failed`; this was an execution-environment restriction, not an Actor result. The elevated rerun succeeded. The configured release memory target is 256 MB; local `RUN_STATS` reports runtime and scan counters but not a reliable high-water memory value.
