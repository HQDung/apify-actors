# Cost report

## Measured local run

The Phase 13 matrix made 5 public HTML requests, processed 15 reviews, and ran the deterministic shared fallback 15 times. No external model provider or proxy was configured, so measured provider/API spend was `$0` for this local run.

Observed resource counters were 6,563,254 response bytes, 1,889 ms runtime, and 209,715,200 bytes reported process RSS.

## Not claimed

Apify compute pricing, cloud memory billing, proxy charges, and external-provider token cost depend on account plan, deployment configuration, and future provider selection. They were not inferred from the local run. Cost per 100 or 1,000 analyzed reviews remains a formula to measure after a cloud run and provider configuration are authorized.
